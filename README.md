# Yamuna Travels

A modern, responsive website for **Yamuna Travels**, a Delhi/NCR-based travel and cab service providing local, airport, railway, outstation and group transportation services across North India.

## 🌐 Website

https://yamunatravels.com

## ✨ Features

- Responsive design for desktop, tablet and mobile
- Cab and vehicle fleet showcase
- Vehicle categories and passenger capacity
- Booking enquiry form
- WhatsApp integration
- Direct "Call Now" contact option
- Service and route information
- Customer testimonials
- Responsive navigation
- Custom favicon and branding
- Optimized static production build

## 🚗 Fleet

The website currently showcases:

- Dzire / Aura — 4+1
- Ertiga — 6+1
- Innova Hycross — 6+1
- Innova Crysta — 6+1 / 7+1
- Hatchback — 4+1
- Tempo Traveller — 12 / 16 / 26 Seater

## 🛠️ Technology Stack

- **Next.js**
- **React**
- **TypeScript**
- **CSS**
- **Lucide React Icons**
- **Next.js Static Export**
